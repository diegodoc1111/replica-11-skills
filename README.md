# Replica: las 11 skills gratis para clonar y mejorar cualquier app con Claude Code

La configuración completa de **Replica** en español: instálala en Claude Code y usa sus 11 skills en orden.

Hecho por [Diego Osorio](https://instagram.com/soydiegoosorio).

**[👉 Abrir la configuración](https://diegodoc1111.github.io/replica-11-skills/)**

## Fuentes verificadas (29-oct-2026)

- Replica: https://github.com/Jakeschincariol/replica-skill (MIT, sin registro ni API key). Instalación: pegar el link en
  Claude y decir "install skill", o como plugin `/plugin marketplace add Jakeschincariol/replica-skill` +
  `/plugin install replica-skill@replica-skill`. Sus herramientas usan Python 3.8+.
- Las 11 skills, su orden y sus reglas (clean-room, solo fuentes públicas y tu cuenta, rebrand obligatorio) son las del README oficial.
- Comandos de instalación de Claude Code: https://code.claude.com/docs/en/setup.
