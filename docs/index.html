Instala Claude Code

Escribe terminal en el buscador de tu computador y ábrela. Pega el comando de tu sistema y dale Enter. No muestra avance mientras descarga: espera a que termine.

WINDOWS
Windows PowerShell
irm https://claude.ai/install.ps1 | iex
MAC
Terminal
curl -fsSL https://claude.ai/install.sh | bash

Cuando termine, cierra la terminal y vuelve a abrirla. Los comandos son los de la página oficial de instalación. ¿Prefieres sin terminal? La app de Claude para el computador trae Claude Code en la pestaña Code.

3

Escribe claude e inicia sesión

Crea una carpeta en Documentos llamada mi-clon. Luego, en la terminal:

WINDOWS
Windows PowerShell
cd Documentos\mi-clon
claude
MAC
Terminal
cd ~/Documents/mi-clon
claude

La primera vez te abre el navegador para entrar con tu cuenta de Claude. Entras, vuelves a la terminal y ya está Claude Code esperando tu mensaje. Si te pide permiso para crear archivos o instalar algo, acéptalo: así trabaja.

Instala esta skill

Claude copia las 11 skills a tu computador. Cuando termine, escribe /exit y vuelve a abrir claude para que aparezcan. Sus herramientas usan Python 3.8 o más nuevo: si no lo tienes, Claude te lo instala.

Úsalas en orden

Cada una lee lo que dejó la anterior en una carpeta llamada replica. Empiezas con la primera y el link de la app que quieres clonar:

Claude Code
/replica-recon https://calendly.com

Y sigues en este orden:

1

2

6

7

Preguntas frecuentes

¿Cuánto me cuesta?

Replica es gratis, sin registro y sin llaves (licencia MIT). Solo pagas Claude Pro, unos 20 dólares al mes. Si la publicas, el dominio y el hosting van por tu cuenta.

¿Queda igualita a la original?

No hay garantía de un clon perfecto. Por eso /replica-diff te da un puntaje real de qué tanto se parece y qué le falta.

¿La puedo vender?

Sí, con nombre y marca propios. Antes revisa que el nombre no sea una marca registrada y lee los términos de lo que usaste. Esto no es asesoría legal: si hay dinero de por medio, consulta a un abogado.

¿La puedo instalar como plugin?

Sí: /plugin marketplace add Jakeschincariol/replica-skill y luego /plugin install replica-skill@replica-skill. Así los comandos quedan como /replica-skill:replica-recon.
